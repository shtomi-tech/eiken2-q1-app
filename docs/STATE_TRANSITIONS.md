## 0. この文書の位置づけ

この文書は、現行コードが実際に行っている状態遷移を表にした動作仕様である。新しい仕様を先に定めた設計案ではない。

状態遷移の実装は、次のファイルに分散している。

- [static/app.js](../static/app.js): 画面ルーター、現在の経路、技能タブのロック
- [static/mode-entry.js](../static/mode-entry.js): 級プロフィール
- [static/mode-serial.js](../static/mode-serial.js): 学習ルートの順序、集計、解放判定
- [static/mode-free.js](../static/mode-free.js): 自由演習への入口
- [static/mode-q1.js](../static/mode-q1.js): 大問1の学習・復習・最終チェック
- [static/mode-q2.js](../static/mode-q2.js): 大問2の4択演習
- [static/mode-q3.js](../static/mode-q3.js): 大問3の設問・根拠文・内容整理
- [static/mode-dictation.js](../static/mode-dictation.js): リスニング・書き取り
- [static/mode-paraphrase.js](../static/mode-paraphrase.js): 言い換え練習

この文書の表記で `技能進捗` と書いた場合、直列ルート専用の回答データではなく、各技能モードが所有する保存データを指す。

## 1. 状態モデル

### 1.1 共通状態

| 状態ID | 意味 | 表示上の状態 | 次へ進める条件 |
|---|---|---|---|
| `READY` | まだ回答・下書きがない | 始める | 主ボタンを押す |
| `PROGRESS` | 回答、下書き、または途中位置がある | 続きから進める | 保存された位置を復元する |
| `DONE` | 対象技能または対象回の完了条件を満たした | 完了 | 復習または次の段階へ進む |
| `LOCKED` | 直列ルート上で前の段階が未完了 | 順番待ち | 前段階が `DONE` になる |
| `SESSION` | 技能内の問題・入力画面を操作中 | 現在の学習 | セッション内の完了条件を満たす |
| `COMPLETE` | 技能内セッションの結果表示中 | 完了確認 | 一覧、次の問題、復習へ進む |

### 1.2 ルート状態

`mode-serial.js` は回答そのものを所有せず、各技能の保存領域から `complete`、`status`、`nextId`、`nextLabel` を計算する。ルート保存領域は現在のプロフィールと段階番号だけを保持する。

```text
eiken_serial_progress_v1
  ├─ version
  ├─ profileId
  └─ currentStep
```

直列コースの現在段階は、原則として「最初に完了していない段階」である。すべて完了した場合だけ最後の段階を現在地として表示する。

実装上は `COURSE_DEFINITIONS` がコースごとの段階配列と集計関数を持ち、`collectCourseSummaries()`、`isUnlocked()`、`stepSummaries()`、`startCurrent()` が両コースに共通する。級ごとの差分は、段階の順序、技能固有の集計、技能モードへ渡す設定に限定する。

## 2. アプリ入口の遷移

| 現在状態 | 操作・条件 | 次状態 | 保存・副作用 |
|---|---|---|---|
| `ENTRY_UNSELECTED` | 2級・準2級・準1級を選ぶ | `ENTRY_SELECTED` | `eiken_grade_profile_v1` にプロフィールを保存 |
| `ENTRY_SELECTED` | 「学習ルート」を選ぶ | `SERIAL_HOME` | `eiken_active_path=serial` |
| `ENTRY_SELECTED` | 「自由演習」を選ぶ | `FREE_HOME` | `eiken_active_path=free` |
| `SERIAL_HOME` | 現在段階の主ボタンを押す | `SKILL_SESSION_SERIAL` | `EikenSerialContext` を設定し、技能モードへ委譲 |
| `FREE_HOME` | 任意の技能を選ぶ | `SKILL_SESSION_FREE` | ルートのロックを適用せず、同じ技能保存領域を使用 |
| 技能画面 | 「一覧へ戻る」 | `SERIAL_HOME` または `FREE_HOME` | `eiken_active_path` に応じて戻り先を決める |
| 任意の画面 | 級を変更する | `ENTRY_SELECTED` | 新しい級を保存する。旧級の技能進捗は削除しない |

`FREE_HOME` はルートの順序ロックを回避する。ただし自由演習で変更された技能進捗は、同じ保存領域を読む直列コースの集計にも反映される。

## 3. 2級・準2級の直列ルート

現行作業ツリーの順序は次の通りである。

```mermaid
flowchart LR
  Q1["大問1・語彙"] --> Q2["大問2・空所補充"]
  Q2 --> W["英作文"]
  W --> D["リスニング"]
  D --> Q3["大問3・長文"]
  Q3 --> FIN["コース完了"]
```

| 段階 | 状態ID | 完了判定 | 未完了時の次アクション |
|---:|---|---|---|
| 1 | `STANDARD_Q1` | 対象回ごとに `finalCheck.cleared=true`。全対象回が完了すると段階完了 | 途中保存、未学習問題、誤答復習、最終チェック |
| 2 | `STANDARD_Q2` | 対象回ごとに全設問が `answered=true` | 最初の未回答問題 |
| 3 | `STANDARD_WRITING` | 対象級の公式課題の完了フラグがすべてtrue（レビュー完了時にtrue） | 最初の未レビュー課題 |
| 4 | `STANDARD_DICTATION` | 対象回の全リスニング設問に回答記録がある | 最初の未回答設問 |
| 5 | `STANDARD_Q3` | 各回の全本文で、設問回答と内容整理の採点が完了 | 未完了本文の設問または内容整理 |
| 6 | `STANDARD_COMPLETE` | 上記5段階がすべて完了 | 最初から復習 |

### 3.1 直列ルートの解放規則

| 判定 | 結果 |
|---|---|
| 段階番号が `currentStepIndex` 以下 | 技能タブを開ける |
| 段階番号が `currentStepIndex` より大きい | ロックされる |
| 現在段階の完了条件を満たす | `currentStepIndex` が次の未完了段階へ移る |
| 全段階が完了 | `DONE`。復習用に先頭から再開できる |

言い換えは主ルート外の追加練習として扱う。未完了でも英作文以降の段階を止めず、自由演習または言い換え画面から利用できる。

## 4. 準1級の直列ルート

```mermaid
flowchart LR
  R1["大問1・語彙"] --> W["ライティング"]
  W --> L["リスニング"]
  L --> R2["大問2・空所補充"]
  R2 --> R3["大問3・長文"]
  R3 --> FIN["コース完了"]
```

各段階について、準1級の3回分を順に評価する。先の回に途中保存があっても、前の回が未完了なら飛ばさない。

| 段階 | 回内の完了条件 | 3回分の段階完了 |
|---|---|---|
| `PRE1_READING1` | 全問に回答し、全問正解。さらに最終チェックが80%以上で `cleared` | 3回すべて完了 |
| `PRE1_WRITING` | 要約・英作文の全課題をレビュー済み | 3回すべて完了 |
| `PRE1_LISTENING` | 全設問に回答 | 3回すべて完了 |
| `PRE1_READING2` | 全設問に回答 | 3回すべて完了 |
| `PRE1_READING3` | 全設問に回答し、各本文の内容整理を採点済み | 3回すべて完了 |

準1級の回内状態は、`eiken_pre1_progress_v1.rounds[roundId]` に次の単位で保存される。

```text
rounds[roundId]
  ├─ questions
  ├─ writing
  ├─ summaries
  └─ finalCheck
```

## 5. 大問1の技能内遷移

### 5.1 通常の1問

| 現在状態 | 操作・条件 | 次状態 | 主な保存値 |
|---|---|---|---|
| `Q1_UNLEARNED` | 問題を開始 | `Q1_FLASH` | `resume.mode=learn`, `stage=flash` |
| `Q1_FLASH` | 暗記カードを最後まで確認 | `Q1_MEANING_CHECK` | `flashIdx` |
| `Q1_MEANING_CHECK` | 意味を回答 | 同状態の回答済み表示 | `checkAnswered`, `wrongLog` |
| `Q1_MEANING_CHECK` | 最終問・誤答あり | `Q1_WRONG_REVIEW` | `wrongChecked` |
| `Q1_MEANING_CHECK` | 最終問・誤答なし | `Q1_PRACTICE` | `stage=practice` |
| `Q1_WRONG_REVIEW` | すべて確認済み | `Q1_PRACTICE` | `wrongReviewed=true` |
| `Q1_PRACTICE` | 4択に回答 | `Q1_DONE` | `learned`, `solvedCorrect`, `needsReview`, `wrongCount` |
| `Q1_DONE` | 次の問題を選ぶ | `Q1_UNLEARNED` または次の未完了問題 | `resume` を削除 |

本番形式で誤答した場合でも問題自体は `learned=true` になる。ただし `needsReview=true` となり、最終チェックの解放を妨げる。

### 5.2 補助セッション

| セッション | 開始条件 | 終了条件 | 終了後 |
|---|---|---|---|
| `Q1_REVIEW` | `needsReview` がある | 復習対象を順に確認 | 次の復習または一覧 |
| `Q1_MEANING` | 意味だけを練習 | 全語句に回答 | 結果表示。通常のCLEAR判定は変更しない |
| `Q1_CYCLE` | 累積・ランダム復習の計画がある | 当該ブロックまたはラウンド完了 | 次ブロック、次ラウンド、または新規学習 |
| `Q1_FINAL` | 全問題正解かつ復習対象なし | 全語句で80%以上 | `finalCheck.cleared=true` または再挑戦 |

## 6. その他の技能内遷移

| 技能 | 状態遷移 | 回・技能の完了条件 |
|---|---|---|
| 大問2 | 一覧 → 未回答問題 → 回答結果 → 次の問題 → 一覧 | 全問 `answered=true`。正答率はゲートに使わない |
| 大問3 | 設問回答 → 根拠文選択 → 判定 → 内容整理 → 本文完了 → 次本文 | 全設問回答＋全本文の内容整理採点 |
| リスニング | 問題 → 4択結果 → 正解なら次問／誤答なら書き取り → スクリプト確認 → 次問 | 全設問に回答記録 |
| 言い換え | 問題 → 下書き → 回答確認 → 自己判定 | 全問題を `solved` または `review` として登録。ただし完了は `solved` |
| 英作文・英作文 | 翻訳 → HEAD → BODY 1 → BODY 2 → CONCLUSION → REVIEW | 課題をレビュー済みにする |
| 英作文・要約 | 第1段落 → 第2段落 → 第3段落 → CHECK | 3段落入力後、レビュー用テキストを完了扱いにする |
| 英作文・Eメール | READ → REPLY → QUESTIONS → CHECK | 返信本文と質問2つを入力し、レビュー済みにする |

英作文の通常課題は6段階、要約とEメールは4段階である。下書きと課題完了フラグは別に保存される。

## 7. 途中再開と離脱

| 離脱地点 | 保存する状態 | 再開時の動作 |
|---|---|---|
| 大問1の暗記・意味チェック | 問題、段階、カード位置、回答位置 | 同じ問題・同じ段階から再開 |
| 大問1の誤答復習 | 誤答一覧、確認済み位置 | 未確認の誤答から再開 |
| 大問1の本番形式 | 問題・回答状態 | 問題単位で再開 |
| 大問2 | 問題番号 | 保存された問題から再開 |
| 準1級の選択問題 | 回、セクション、問題番号、回答状態 | 同じ回・セクションから再開 |
| 準1級の語彙最終チェック | 問題順、位置、正答数 | 同じ最終チェック位置から再開 |
| リスニング | 回、問題番号、問題／書き取り／確認 | 同じモードから再開 |
| 英作文 | 課題番号、入力ステップ、下書き | 未完了の最初のステップから再開 |

完了画面へ到達したセッションは `resume` を削除する。ブラウザを閉じただけの場合は、完了画面に到達していなければ途中状態を残す。

| リスニング | `eiken_dictation_progress_<level>_<round>` | 問題別回答 |
| リスニング再開 | `eiken_dictation_resume` | 回、問題番号、表示モード |

共有URLが有効な場合も、各技能のローカル保存を基本にし、対応するクラウド同期層が全体または技能別の進捗を同期する。匿名利用ではlocalStorageだけで動作する。

## 9. 状態遷移上の不変条件

今後の変更では、次の条件を壊してはならない。

1. 直列ルートは、未完了の前段階を飛び越えて次段階を解放しない。
2. 自由演習はルートのロックを回避できるが、回答データの保存形式は直列ルートと共有する。
3. 技能の完了条件は、正答数だけでなく、その技能固有の学習行為を含める。
4. 大問1の最終チェックは、通常問題の正解・誤答復習が完了するまで解放しない。
5. 準1級大問1は、全問正解だけでは完了にせず、最終チェック80%以上を要求する。
6. 準1級大問3は、設問回答だけでは完了にせず、本文ごとの内容整理も要求する。
7. 下書き保存と課題完了は別状態として扱う。
8. 問題セットを変更しても、別セットの進捗を削除しない。
9. 完了画面に到達したセッションの再開状態は削除する。
10. 進捗キーや既存の保存形式を変更する場合は、移行または旧形式の読み込みを用意する。

## 10. 最低限の検証ケース

| ケース | 期待結果 |
|---|---|
| 初回に級を選び、直列ルートを開く | 最初の段階が `READY`、後続は `LOCKED` |
| 大問1を途中で閉じる | 同じ問題・段階から再開できる |
| 大問1で誤答する | `needsReview=true`、最終チェックは解放されない |
| 大問1の誤答復習を完了する | 最終チェックへの導線が現れる |
| 最終チェックで79%以下 | `cleared=false`、再挑戦できる |
| 最終チェックで80%以上 | 対象回が `DONE`、次の回へ進める |
| 大問2で全問不正解 | 回は完了扱いになるが、正答率は記録表示に留まる |
| 準1級大問1を全問回答するが1問誤答 | 最終チェック前の再回答対象になる |
| 準1級大問3の設問だけ完了する | 内容整理が未完了なら段階は未完了 |
| 自由演習で技能を完了する | 直列ルートの集計にも反映される |
| 級を変更する | 旧級の進捗を残したまま、新しい級を表示する |
| 問題データの総数が変わる | 旧 `CLEAR` を無条件に維持しない |

## 11. 仕様と実装の差分管理

状態遷移を変更する場合は、次の順で更新する。

1. この文書の該当表を更新する。
2. 完了条件と保存キーを確認する。
3. 状態遷移に対応する検証ケースを追加または更新する。
4. ブラウザで初回、途中再開、完了、次段階解放を確認する。
5. データ検証、構文検証、デプロイ後の公開ファイル確認を行う。

状態名を画面文言だけで変更しても、保存データの意味が変わる場合は状態遷移の変更として扱う。
