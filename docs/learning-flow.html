順序ロックあり。前の主要技能を完了すると次が解放される。回ごとの途中状態も引き継ぐ。

MODE A — 学習ルート（順序あり）

技能を順番に解放していく

2級・準2級ルート

G2 / PRE-2

解放条件：主要技能ごとに過去問3回分をすべてCLEARすると次の段階が解放。「言い換え」は主ルート外の追加練習。

1Vocabulary大問1（語彙）3回分の語彙・各回の最終チェックをCLEAR
→
2Cloze大問2（空所補充）3回分の本文・空所補充を確認
→
3Writing英作文3回分を書き・参考解答とレビュー
→
4Listeningリスニング3回分の全設問・書き取り確認
→
5Reading大問3（長文）3回分の本文・設問・内容整理

準1級ルート

PRE-1 · 過去問3回分

2026年度第1回・2025年度第3回・2025年度第2回を切り替えて演習。各段階で3回分を完了すると次が解放。

1Vocabulary大問1（語彙）意味確認から4択・最終チェックまで
→
2Writingライティング英文要約・英作文を組み立て・レビュー
→
3Listeningリスニング3回分の音声・書き取り確認
→
4Cloze大問2（空所補充）3回分の空所補充を確認
→
5Reading大問3（長文）長文・根拠文・内容整理を完了
主要技能（3回分でゲート） 補助練習（ゲート対象外） Clay＝復習・最終チェック（要注意アクション）
各技能の内部ステップ

技能を選んだ後の流れ

各技能は数ステップ構成。誤答・根拠不一致は復習モードへ回せる。

大問1（語彙）

Vocabulary · 3 steps
意味・語源・例文を確認→ 意味チェック→ 本番形式の4択

＋ 誤答復習／最終チェック（80%以上で回の完了）

大問3（長文）

Reading · 3 steps
4択で解答→ 根拠文を本文からタップ選択→ 判定（正誤＋根拠一致度）

＋ 内容整理（要約穴埋め）／誤答・根拠不一致の復習

リスニング

Listening · 3 steps
設問ごとに音声再生→ 4択回答→ 誤答のみ書き取り・スクリプト確認

級・回セレクタで設問を切り替え

英作文

Writing · 6 steps
訳す→ Yes / No→ BODY 1→ BODY 2→ CONCLUSION→ 全体レビュー

目安：2級 80–100語／準2級 50–60語（語数）

MODE B — 自由演習（順序なし）

6技能から直接選ぶ

ロックなし。2級・準2級では6技能、準1級では5技能から、その日の1つを選んで演習。回答・下書き・途中位置は学習ルートと同じ保存領域を使う。

Reading大問3（長文）
PROGRESS · 進捗の保存

進捗はモードごとに別々のキーで localStorage に保存。生徒別URL（?s=…&t=…）が付き公開設定が有効なら、技能・モード別のappIdで Supabase（app_students / app_progress）へ同期する。統合前の進捗もそのまま引き継がれる。
